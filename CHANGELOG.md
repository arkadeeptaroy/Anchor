# Changelog

## 0.4.0

- Add dark-mode, SAVE10 discount and price-sorting scenarios with shared interactive controls.
- Model global color inversion, lost shipping fees, missing products and incorrect currency formatting as executable regressions.
- Expand protection to eight feature groups and 14 regression checks plus scenario acceptance.
- Add exhaustive lock combinations, seeded input stress, repeatability, malformed-input and Chromium browser checks.
- Preserve the builder workspace and local product photography.

## 0.3.0

- Default to a side-by-side comparison driven by identical user inputs and evaluated fixture code.
- Add a guided Run demo control and immediate regression, order-total and illustrative repair-credit metrics.
- Highlight incorrect outputs and restored behavior at the affected component level.
- Replace vector product illustrations with four original generated WebP photographs, embedded for offline use.
- Retain individual storefront views, feature protection, code review and the acceptance gate.

## 0.2.0

- Integrated feature protection into the chat, code and preview workspace.
- Added protected dependency inspection, change review and comparative test results.
- Refined responsive layouts, interaction feedback, typography and light/dark appearance.
- Retained deterministic scenario patches and the regression gate.
- Documented product scope, validation evidence and next experiments.

## 0.1.0

- Established the standalone feature-lock prototype and bundled storefront scenarios.
- Implemented patch validation, dependency protection, regression checks and a credit estimator.
